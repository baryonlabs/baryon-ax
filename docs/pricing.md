> 결정일 2026-11-26 · **v0.8.0부터 적용 예정.** 그 전까지는 [LICENSE](../LICENSE)(Baryon AX Community License 1.0)와

Baryon AX는 회사 서버에 설치해 쓰는(셀프 호스팅) 제품입니다. 오픈소스 기본 기능은 무료이고, **Pro 기능**은
**로그인 사용자**와 **연결 기기** 수에 따라 연 단위로 결제합니다. 소스는 Pro 기능까지 모두 공개되어 보안 심사에서
직접 읽을 수 있습니다. 쓰는 데 라이선스가 필요할 뿐입니다.

### FREE에 들어 있는 것 (오픈소스 기본)

- 근거 답변 채팅과 출처 인용, 웹 화면
- 문서 올리기와 파싱(HWP·HWPX·PDF·Office·이미지, 파서 사이드카 구성 시)
- 지식 공백 감지와 전문가에게 먼저 묻기, 암묵지 게시
- MCP 서버(`search_documents`, `ask` 등), 슬랙·디스코드 봇 예제
- 질문 속 웹 링크 읽기

### Pro (INDIVIDUAL부터)

- 상주형 음성 비서: 바리온 비서 앱, 전화(SIP), 말과 화면 카드
- 목표 에이전트(번호가 붙는 백그라운드 작업), 폰 알림·알람
- 사진·녹음 이해
- Gmail·캘린더·슬랙 연동(메일 초안·발송 확인, 일정 조정)
- 웹사이트 크롤링(`/v1/crawls`, `crawl_site`)

### BASIC에서 더해지는 것

- OIDC 로그인(SSO)과 서비스 계정 위임
- 조직·역할 권한 관리 화면
- 감사 로그 내보내기와 보존 정책
- 온톨로지 꾸러미(승인 워크플로), 코드 저장소 지식(repo-sync)
- 슬랙 비서 브리지(슬랙에서 메일 초안·일정 맡기기)

### CUSTOMIZED

- BASIC의 모든 것 + 사용자·기기 추가
- 지원 서비스: 설치 대행, 사내 IdP(AD·SSO) 연동, 그룹웨어·ERP 커넥터 개발, 사내 GPU 모델 서빙 구성,
  보안 질의서·감사 대응 자료, 장애 대응 SLA, 호스팅·SaaS 제공 권리

## 무엇을 세나요

- **로그인 사용자**: 웹이나 앱에 로그인하는 사람 계정 수입니다. 슬랙에서 봇에 묻기만 하는 사람은 세지 않습니다.
- **연결 기기**(클라이언트): 바리온 비서 앱이 설치된 폰·데스크톱, 서버에 연결된 슬랙·디스코드 봇, MCP 클라이언트 연결
  (Claude, IDE, 에이전트 채팅 앱)의 수입니다.
- **서버**: 서버 대수는 세지 않습니다. 같은 라이선스로 운영·백업·검증 서버를 함께 둘 수 있습니다.
