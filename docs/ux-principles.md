## 0. 요약

이번 개편은 "예쁘게"가 아니라 **불확실한 AI를 안전하게 쓰기 위한 인터페이스**를 만드는 작업이었다.

- **UX 10원칙**: 상태 가시성, 사용자 통제, 일관성, 오류 예방·회복, 인식 우선, 효율, 미니멀리즘, 도움말
- **AI 앱 10원칙**: 능력·한계 고지, 근거(출처), 불확실성, 통제권, 피드백 루프, 처리 과정 설명, 복구, 프라이버시, 점진적 공개, 연속성
- 결과: 빈 화면·스트리밍·근거 없음·오류·모바일에서 **다음 행동이 항상 보이는 UI**

## 1. UX 10원칙과 적용

| # | 원칙 | 적용 | 확인 |
|---|---|---|---|
| 1 | **시스템 상태 가시성** | 스트리밍 스피너·"검색·생성 중" 상태, `aria-live`, 처리 과정(trace), 업로드·검증·잡 상태, 토스트 | `role="status"`, `.composer .live`, 테스트 |
| 2 | **실제 세계와 일치** | 한국어 우선 마이크로카피, 조직·역할·모델을 헤더 컨텍스트 칩으로 표시, "근거", "암묵지", "온톨로지 꾸러미" 등 도메인 용어 유지 | ko/en 카피, 스크린샷 |
| 3 | **사용자 통제와 자유** | 생성 **중지**, **다시 생성**, 대화 지우기(확인), 문서 삭제 확인, 편집 취소, `Esc`로 모달·드로어 닫기 | E2E stop/clear |
| 4 | **일관성과 표준** | 디자인 토큰(색·간격·라운드·그림자), 버튼 계층(primary/ghost/icon), 칩·배지·빈 상태·오류 상태 통일 | CSS 토큰, 빌드 |
| 5 | **오류 예방** | 빈 입력 전송 비활성, 중복 전송 방지, 파괴적 작업 확인, 공백/닫힌 권한에 대한 사전 안내 | E2E 버튼 상태 |
| 6 | **기억보다 인식** | 빈 채팅 추천 질문, 출처 칩(문서·청크), 카테고리/태그 필터, 질문 출처 배지(공백/템플릿), 대화 localStorage 복원 | 스크린샷, E2E |
| 7 | **유연성과 효율** | `Shift+Enter` 전송, 다중 파일 업로드, 문서 필터, 관리자 빠른 이동, 키보드 포커스 링 | E2E |
| 8 | **미니멀리즘** | 940px 본문 폭, 메타데이터는 muted, 처리 과정은 접힘, 한 화면 한 목적 | 스크린샷 |
| 9 | **오류 회복** | 부분 응답 보존, 오류 시 명확한 문구, 다시 생성, 스캔/피드백 실패가 채팅을 막지 않음 | stop/오류 처리 |
| 10 | **도움과 문서** | 인라인 힌트(범위·단축키), 빈 상태 안내, 근거 없음 경고, docs 링크 | 카피 |

## 2. AI 앱 10원칙과 적용

| # | 원칙 | 적용 | 확인 |
|---|---|---|---|
| 1 | **능력과 한계를 먼저 알린다** | "온프레미스 프로필", 모델명, RAG 토글, "문서는 조직·역할 범위에서만 검색" 문구 | 헤더·컴포저 |
| 2 | **근거를 보여준다** | 인용 칩(문서명·청크), 출처 뷰어(원문/다운로드), 원문은 클라이언트에 전체 노출하지 않음 | E2E citation |
| 3 | **불확실성을 숨기지 않는다** | 검색 근거가 없으면 **경고 배너**("중요한 결정 전에 출처 확인"), 근거 수 표시 | 스크린샷 |
| 4 | **통제권을 사람에게** | 생성 중지·재생성·복사, 게시/승인/삭제 확인, ACL·조직 컨텍스트 상시 표시 | E2E |
| 5 | **피드백 루프** | 답변 👍/👎 → `POST /v1/feedback` (trace_id 연결) → 관리자 조회·감사 이벤트 | `test_feedback.py` |
| 6 | **처리 과정을 설명** | trace(정책·검색·메모리·모델·감사) 접힘 패널, 단계별 시간 | E2E/스크린샷 |
| 7 | **복구 가능하게** | 부분 응답 유지, 다시 생성, 오류 토스트, 피드백 실패는 무시(응답 유지) | 코드·E2E |
| 8 | **프라이버시·맥락 보호** | 조직/역할 스코프, ACL 편집 관리자 제한, 인용은 메타데이터만, 피드백 저장 최소화 | security.md |
| 9 | **점진적 공개** | trace·출처·설정 카드·꾸러미 상세를 필요할 때 펼침 | UI 구조 |
| 10 | **연속성** | 채팅 localStorage 복원, 새 대화/지우기, Mem0 메모리, 암묵지 축적 | E2E/수동 |

## 3. 이번에 실제로 바뀐 것

| 영역 | 이전 | 이후 |
|---|---|---|
| 빈 채팅 | 인사말 한 줄 | 추천 질문 4개 + 안내 + 바로 전송 |
| 응답 중 | 전송 버튼 비활성 | **중지 버튼** + 스피너 + `aria-live` |
| 응답 후 | 복사/재시도/평가 없음 | **복사·다시 생성·👍/👎** |
| 근거 없음 | 작은 "출처 없음" 텍스트 | **경고 배너** + 근거 수 |
| 대화 | 새로고침 시 사라짐 | **localStorage 복원** + 지우기 확인 |
| 모바일 | 사이드바 `display:none` | **드로어 + 백드롭 + 닫기** |
| 접근성 | 포커스 스타일 없음 | `:focus-visible`, skip link, `Esc`, `aria-live`, reduced motion |
| 디자인 | 페이지별 제각각 | **토큰 기반** 버튼·카드·칩·빈 상태·토스트 |
| 헤더 | 제목·선택 컨트롤만 | 조직/역할/모델 **컨텍스트 칩** + 일관된 액션 |

## 5. 남은 개선

1. **자동 접근성 감사**: axe-core를 E2E에 추가해 대비·레이블·랜드마크를 정량 측정.
2. **키보드 전체 여정**: 문서 편집·꾸러미 승인까지 Tab 순서 검증.
3. **AI 신뢰도 표시**: 현재는 "근거 있음/없음" 이진값 → 검색 점수·인용 커버리지 기반 3단계.
4. **응답 편집·재질문**: 답변을 수정해 다시 묻는 흐름.
5. **모바일 하단 안전영역**: iOS 노치/홈 인디케이터 대응 (`env(safe-area-inset-bottom)`).
6. **사용성 테스트**: 실제 사용자 5명 태스크 기반 측정(질문→근거 확인까지 시간).
