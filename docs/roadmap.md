# 로드맵 · 대상 고객 · 공개 범위

> 기준일: 2026-11-21 · 다음 검토: v0.8.0 릴리스 시

이 문서는 다음 릴리스에서 **무엇을 먼저 만들지**와 **무엇을 소스로 공개하고 무엇을 지원으로 제공하는지**를 정합니다. 기능 단위 현황은 [features.md](features.md), 이슈 단위 작업은 GitHub Issues를 봅니다.

## 1. 먼저 겨냥하는 고객

**1순위: 한국 기업의 DX·AX 담당 조직**

| 이유 | Baryon AX에서 이미 갖춘 것 |
| --- | --- |
| 문서가 HWP·HWPX·스캔 PDF로 쌓여 있습니다. | kordoc·docling 파서 라우팅, 구조 청킹 |
| 데이터를 외부 SaaS로 보낼 수 없습니다. | 온프레미스·폐쇄망 구성, 사내 GPU(vLLM) 연결 |
| 도입 전에 보안 심사를 통과해야 합니다. | 조직·역할 ACL, 감사 로그, PR마다 보안 점검 |
| 문서에 없는 판단 기준이 사람에게만 있습니다. | 지식 공백 감지 → 전문가 질문 → 게시 루프 |

**2순위: 해외·국내 개발자와 소규모 플랫폼 팀(10인 미만 무료)**

OpenAI 호환 모델·임베딩, MCP 도구·서버, Slack·Discord 봇처럼 **표준 인터페이스로 연결되는 부분**은 이 그룹이 먼저 써 보고 피드백을 줍니다. 홈페이지와 README의 영어 판은 이 그룹을 위한 것입니다.

판단 기준: 두 그룹의 요구가 부딪히면 1순위의 요구(보안 심사, HWP, 폐쇄망)를 먼저 처리합니다.

## 2. 공개 범위와 라이선스

Baryon AX는 소스 공개 멀티 라이선스입니다([licensing.md](licensing.md)). 개인·10인 미만 조직·30일 도입 검토는 무료(Community License 1.0), 10인 이상 조직의 운영 사용과 호스팅 제공은 상용 라이선스입니다. **기업이 도입을 결정하는 데 필요한 기능은 모두 소스로 공개합니다.** (2026-11-26: v0.8.0부터 오픈소스 기본 + Pro 유료로 바꿉니다. Pro 기능도 소스는 공개하고, 운영 사용에 라이선스가 필요합니다. [pricing.md](pricing.md)) 보안·운영 기능을 유료로 막아 두면 보안 심사에서 "핵심 통제가 소스로 검증되지 않는다"는 이유로 도입이 막히기 때문입니다.

| 영역 | 소스 공개 (이 저장소) | 지원 서비스 (Baryon Labs) |
| --- | --- | --- |
| 대화·지식·암묵지 루프 | 전체 | 업무별 질문 템플릿·온톨로지 팩 설계 |
| 인증·권한 | OIDC 검증, 역할 매핑, 서비스 계정 위임, 사용자·조직 관리 UI | 사내 IdP(AD·SSO) 연동 작업 |
| 감사·보안 | 감사 로그·검색·내보내기, 보존 정책, 보안 CI | 보안 질의서 작성, 감사 대응 자료 |
| 운영 | 백업·복구·업그레이드 런북과 스크립트, Compose·Kubernetes 구성 | 설치 대행, 업그레이드 대행, 장애 대응 SLA |
| 연동 | OpenAI 호환 모델·임베딩, MCP, Slack·Discord 예제 | 사내 시스템(그룹웨어·ERP) 전용 커넥터 개발 |
| 모델·GPU | 모델 어댑터, 하드웨어 선택 가이드 | 사내 GPU 모델 서빙 구성·튜닝 |

원칙:

- 지원 서비스는 **사람의 시간이 드는 일**(설치, 연동, 심사 대응, 맞춤 개발)입니다. 코드 기능을 숨기지 않습니다.
- 고객 프로젝트에서 만든 범용 기능은 고객 정보를 제거한 뒤 이 저장소로 되돌립니다.
- 고객사 설정, 접속 정보, 트래픽 수치는 이 공개 저장소에 넣지 않습니다.
