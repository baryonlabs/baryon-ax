라이선스 주의사항

Redis

버전에 따라 라이선스가 다릅니다. 7.2 이하는 BSD-3-Clause, 7.4~7.8은 RSALv2/SSPLv1, 8 이상은 RSALv2/SSPLv1/AGPLv3 중 선택입니다. 배포 버전을 고정하고 확인하세요. BSD 조건이 필요하면 Valkey를 검토하세요.

Langfuse

코어는 MIT, /ee 디렉터리의 일부 엔터프라이즈 기능은 상용 라이선스입니다. EE 기능을 사용하지 않으면 MIT 범위로 셀프호스팅할 수 있습니다.

Docker

Docker Engine/Moby는 Apache-2.0입니다. Docker Desktop은 별도 상용 약관이 적용될 수 있으므로 서버 배포에는 Docker Engine을 사용하세요.

모델 가중치

vLLM·Ollama는 서빙 소프트웨어이며, 실제 모델 가중치는 별도 라이선스를 따릅니다. 상용 배포 전에 모델 라이선스를 확인하세요.

psycopg · LGPL-3.0

PostgreSQL 드라이버는 LGPL-3.0입니다. 동적 링크·재배포 시 의무 사항을 확인하세요.

이 페이지는 apps/api/src/baryon/open_source.py의 인벤토리에서 생성됩니다. 앱의 Settings → Open Source 탭과 동일한 데이터이며, 변경 후 python3 scripts/build_open_source_site.py를 실행하세요.
