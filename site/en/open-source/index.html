License caveats

Redis

The license depends on the version. Redis 7.2 and earlier is BSD-3-Clause; 7.4–7.8 is RSALv2 or SSPLv1; Redis 8 and later offers RSALv2, SSPLv1, or AGPLv3. Pin and verify the deployed version. Consider Valkey if you need BSD terms.

Langfuse

The core is MIT; some enterprise features under /ee are commercially licensed. Self-hosting without EE features stays within the MIT scope.

Docker

Docker Engine/Moby is Apache-2.0. Docker Desktop may have separate commercial terms; use Docker Engine for server deployments.

Model weights

vLLM and Ollama are serving software; the actual model weights carry their own licenses. Verify the model license before commercial distribution.

psycopg · LGPL-3.0

The PostgreSQL driver is LGPL-3.0. Review dynamic-linking and redistribution obligations.
