# 휴가 규정 (가상의 회사 데모)

> Baryon AX 데모용 가상 회사(데모상사) 규정입니다.

| 구분 | 일수 | 비고 |
| --- | --- | --- |
| 연차 | 입사 1년 뒤 15일, 2년마다 1일 추가(최대 25일) | 1년 미만은 매달 1일 |
| 경조 휴가 | 본인 결혼 5일, 부모 사망 5일, 자녀 결혼 1일 | 증빙 제출 |
| 리프레시 휴가 | 근속 5년마다 10일 | 1년 안에 사용 |

- 연차는 3일 전까지 인사 시스템에 신청하고, 5일 이상 연속이면 2주 전에 팀장과 협의한다.
- 남은 연차는 다음 해로 최대 5일까지 넘길 수 있다.
